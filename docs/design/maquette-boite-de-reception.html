Aucune couleur d'accent. Le bouton principal est à l'encre ; l'orange et le bleu ne signalent qu'un état.

Principes

  1. Une seule file d'attention. On répond depuis la liste, sans ouvrir le chat.
  2. Arrêter reste visible, même pendant la saisie.
  3. Les outils sont des lignes : verbe, cible, résultat. Le diff s'ouvre sur place.
  4. Un envoi non confirmé le dit, avec son action de reprise.
  5. Lire ne touche pas au Mac. Le focus bureau est une action du menu.
